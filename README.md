# Enterprise CRM System

A full-stack Customer Relationship Management system built using React.js, Node.js, Express.js and MongoDB.

## Features

- User Login and Registration
- JWT Authentication
- Role-Based Access Control
- Lead Management
- Lead Status Tracking
- Deal Management
- Deal Pipeline
- Sales Dashboard
- Activity and Email Logs
- Admin and Sales User Roles
- MongoDB Database
- REST APIs
- Responsive UI

## Technology Stack

Frontend:
- React.js
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

Authentication:
- JWT
- bcryptjs

## Project Structure

frontend/
backend/
models/
controllers/
routes/
middleware/

## Roles

Admin:
- Manage leads
- Manage deals
- Manage activities
- Delete records

Sales User:
- View and add records
- Update leads and deals
- Manage activities

## How to Run

### Backend

cd backend
npm install
npm start

### Frontend

cd frontend
npm install
npm run dev
